# E-Portfolio PPG — Praktik Mengajar Mandiri

Template website statis dengan HTML, CSS, dan JavaScript. Semua file dipisahkan sesuai struktur yang disarankan.

## File
- `index.html` — beranda
- `profil.html` — profil dan filosofi mengajar
- `siklus-1.html` sampai `siklus-4.html` — dokumentasi setiap siklus
- `analisis.html` — analisis dan refleksi lintas siklus
- `artefak.html` — katalog artefak dan checklist
- `style.css` — seluruh desain bersama
- `script.js` — navigasi mobile, dropdown, filter artefak

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Buka `index.html` langsung di browser atau gunakan ekstensi Live Server.
4. Sesuaikan nama, profil, kelas, materi, tanggal, dan isi refleksi.
5. Pada tautan bertuliskan “Tambahkan tautan”, ganti atribut `href="#"` dengan URL Google Drive/YouTube/dokumen yang sudah diatur aksesnya.
6. Untuk menyematkan video, ganti placeholder video di file siklus dengan kode embed dari layanan video yang digunakan.
7. Uji seluruh tautan dan tampilan mobile sebelum dipublikasikan.

## Catatan penting
- Ini adalah template front-end statis, bukan aplikasi dengan database atau login.
- Kolom analisis/refleksi belum menyimpan data. Salin jawaban ke dokumen sebelum meninggalkan halaman.
- Jangan mengunggah dokumen yang memuat data pribadi siswa; samarkan identitas siswa jika diperlukan.
- UTS diwakili Siklus 1; UAS diwakili Siklus 2–4; komponen Topik 3 tersebar di halaman siklus, analisis, artefak, dan profil.
